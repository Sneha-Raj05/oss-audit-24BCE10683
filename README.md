## Project Description
This repository contains 5 shell scripts developed as part of the Open Source Software (OSS) Capstone Project. These scripts audit the system identity, package status, disk permissions, and logs specifically for a MySQL environment on Linux.

## Script Descriptions
1. **Script 1 (System Identity):** Reports kernel, user, and uptime data.
2. **Script 2 (Package Inspector):** Checks if MySQL-server is installed and shows metadata.
3. **Script 3 (Disk Auditor):** Audits permissions and sizes of MySQL-related directories.
4. **Script 4 (Log Analyzer):** Scans MySQL error logs for specific keywords.
5. **Script 5 (Manifesto):** Generates a personalized OSS philosophy text file.

## Execution Instructions
1. Clone the repo: `git clone [Your Repo URL]`
2. Give execution permissions: `chmod +x *.sh`
3. Run scripts: `./script1.sh`, `./script2.sh`, etc.

## Dependencies
- Linux OS (Ubuntu/Debian preferred)
- MySQL Server (for Script 2, 3, & 4)
